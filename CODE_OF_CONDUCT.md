# Code of Conduct

## Our standard

We welcome contributors regardless of background or experience. Be respectful, discuss the code rather than the person, and make technical disagreements specific and reproducible.

Unacceptable behavior includes harassment, threats, discriminatory language, deliberate disclosure of private information, publishing unredacted game captures, and disrupting project discussions.

## Enforcement

Report conduct concerns privately to the maintainer through the GitHub account `@he11fireUA`. Do not use a public issue when a report contains private or identifying information.

Maintainers may edit or remove contributions, comments, issues, and other material that violate this policy, and may temporarily or permanently restrict participation when necessary.

## Scope

This policy applies in project repositories, issue trackers, pull requests, release discussions, and other spaces where a person represents the project.
